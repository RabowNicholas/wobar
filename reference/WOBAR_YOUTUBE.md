# WOBAR YOUTUBE DESCRIPTION SYSTEM

Descriptions are **utility floor** (logistics, links, metadata) wrapped around a
**light-register** hook. Exempt from the full mirror principle; NOT exempt from Law 0.
Clean, confident, no woo, no hype-spam. The outsider reads a moody bass set; the insider
reads the descent. Dual-valid, but discovery comes first.

---

## THE HARD RULES (research-backed — do not break)

### The fold
- Only the **first ~150 characters** (2–3 lines) show in search results + above the
  "…more" fold. Most viewers never expand.
- **That real estate carries: primary keyword + the #1 conversion link.** For Wobar the
  conversion link is **streaming** (Spotify first, per Nick).
- First sentence must contain the long-tail keyword and stay **consistent with the title**.

### Title
- **Under 60 characters** or it truncates in search. Front-load genre + identity.

### Tracklist → chapters (auto-generates YouTube chapters)
- **First timestamp MUST be `0:00`.**
- **Minimum 3 timestamps, each ≥10s apart.** Below this, chapters don't generate.
- **Chronological order only.** `MM:SS` or `HH:MM:SS`.
- Each entry: **artist — track title** (credits artists, boosts search, aids navigation).
- Chapters materially lift watch-time + retention and can surface in search. Never skip.

### Links / CTA
- Put the streaming/conversion link **above the fold** (highest intent).
- Full links block goes **after the tracklist**, never interspersed (keeps tracklist clean).
- Streaming first (conversion), then socials/subscribe.

### Hashtags
- **3–5 max**, bottom only. First 3 render as clickable tags above the title.
- Genre + brand aligned. Excess hashtags read as spam and cut credibility.

### Tags (the separate YouTube "tags" field, not description)
- 10–15: DJ name, genre ("deep dubstep", "heavy bass"), mix type ("dj set", "live mix"),
  location, featured artists.

### Body length
- Aim ~107–250 words of real copy (keyword-rich) before/around the tracklist. Full field
  cap is 5,000 chars — no need to fill it.

## VOICE — inherit COPY, act-weighted

- **Register:** LIGHT (temperature B / sensory, or A / wry) for the body; UTILITY for
  links + tracklist. Never source/daemon register in a description.
- **Act weather:** weight the hook to the set's dominant act (see EMOTIONAL_REGISTER).
  A sunrise/Act-4→5 set leans release/exhale; an Act-2/3 set leans sinking/held.
- **Anti-vocabulary applies** (plain register). No "good vibes," no "healing frequencies,"
  no "🔥🔥 OUT NOW." Say what the set actually is and how it hits.
- Run **THE BODY TEST** on the hook: at least one line grounded in the physical/sonic.
